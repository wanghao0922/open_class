# 课堂紫外吸收光谱

本目录保存教师提供的12张PNG原图。图片未经裁剪、重绘或重新计算，随前端构建一起发布。`manifest.json`记录结构编号、原始文件名、图片标注类型和SHA-256；显示映射在`../../MoleculeSpectrum.tsx`。

| 结构编号 | 图片 | 图片标注类型 |
| --- | --- | --- |
| `none__acid` | cinnamic-acid.png | 文献数据重绘 |
| `none__methyl` | cinnamic-methyl.png | 文献峰位约束拟合预测 |
| `none__ethylhexyl` | cinnamic-ethylhexyl.png | 文献峰位约束拟合预测 |
| `methoxy_ortho__methyl` | ortho-methoxy-methyl.png | 计算预测 |
| `methoxy_meta__methyl` | meta-methoxy-methyl.png | 计算预测 |
| `methoxy_para__methyl` | para-methoxy-methyl.png | 文献数据重绘 |
| `methoxy_ortho__ethylhexyl` | ortho-methoxy-ethylhexyl.png | 文献数据重绘 |
| `methoxy_meta__ethylhexyl` | meta-methoxy-ethylhexyl.png | 文献数据重绘 |
| `methoxy_para__ethylhexyl` | para-methoxy-ethylhexyl.png | 文献数据重绘 |
| `methoxy_ortho__acid` | ortho-methoxy-acid.png | 文献数据重绘 |
| `methoxy_meta__acid` | meta-methoxy-acid.png | 峰位约束拟合预测 |
| `methoxy_para__acid` | para-methoxy-acid.png | 文献数据重绘 |

只按完整结构编号匹配。当前可操作的12种结构均有对应光谱，不使用其他分子的图片替代。历史结构若无图片，显示“暂无对应光谱”。

图片中的溶剂、来源、归一化和预测说明均保留；“文献数据重绘”“计算预测”“峰位约束拟合预测”和“文献峰位约束拟合预测”为原图标注，不表示网页进行了文献复核或计算。图片点击后可放大，也可在新窗口查看原尺寸。
